# What this project keeps, and why

The corpus is not the deliverable. The deliverable is a corpus that can be
**rebuilt better later**, by a model that does not exist yet. Everything below
is kept on the assumption that in a year something will read these scans more
accurately than anything available today, and the only thing standing between
us and that better reading should be the cost of the new model -- never the
cost of finding the book again, or of discovering what was already tried.

## The rule

> Anything that cost money, and anything a machine generated that a machine
> would have to generate again, is kept. Source PDFs are not: they are large,
> they are public, and a link is enough. **A link IS kept, and the page count
> that proves it is the same edition.**

## What is kept, and where

| thing | where | why |
|---|---|---|
| Raw OCR, per engine, per page | `data/ocr_staging/<work>/<engine>_pages<A>-<B>.json` on `ocr-staging/<work>` | This is what was paid for. Never overwritten, never merged in place — a better run is a NEW file beside it. |
| Per-page confidence and layout | same files | Sarvam's `data-confidence`, Vision's per-word scores. A future pass can weigh them. |
| What the engines disagreed on | regenerated by `tools/ocr_conflicts.py` | Derived, so not committed — but the detector is versioned, and a conflicts file written before 18 Sep 2026 overstates the work about fivefold. |
| Which PDF, which pages, which edition | `admin/config/ocr_sources.json` | Item, file, URL, the PDF's own page count, the OCRed range, how it was verified. |
| Every rupee spent | `admin/config/cost_ledger.jsonl` | Append-only. One row per billed run. |
| Pages asked for that never came back | `admin/config/ocr_sarvam_missing.json` | Built from the staged files, not from workflow results — every one of them sits under a run that reported success. |
| What went wrong before | `docs/MISTAKES.md` | Not a diary. See "enforcement" below. |
| The procedure for spending money | `docs/OCR_RUNBOOK.md`, enforced by `tools/ocr_batch.py --preflight` | Prose nobody is obliged to read is not a control. |

## Why source PDFs are NOT kept

Thousands of books at 500+ pages is terabytes, and every one of them is already
hosted by archive.org or Google Drive, who are better at storing files than we
are. What must never be lost is the **identity** of the edition: two scans of
"Bhāgavata Sāroddhāra" differing by 101 pages are different books, and OCR run
against the wrong one produces text that disagrees with itself everywhere. That
is why `ocr_sources.json` records the page count and how it was checked, and why
a source is confirmed by a number rather than by a title.

## Enforcement, not documentation

A rule that depends on someone remembering it is not a rule. Each of these is
enforced by something that fails:

| rule | what enforces it |
|---|---|
| Nothing is billed until the path has been proven end to end, today, on one small volume | `tools/ocr_batch.py --preflight` refuses to dispatch without a same-day pilot receipt |
| A batch plan is built from the source manifest, never typed from memory | `tools/ocr_plan_from_sources.py`, which also asserts the chunks cover the range exactly once |
| A paid run reports what it produced, not that it reached the end of its code | `sarvam_docai.py` exits non-zero if any page failed |
| A Gemini run cannot exceed its budget | `gemini_resolve_conflicts.py` totals real usage after every call and stops before the next one |
| Enrichment stays attached to the text it describes | `tools/check_sidecars.py`, in CI |
| The corpus stays in Unicode NFC | `tools/normalize_nfc.py --check`, in CI |
| No private-source provenance leaks into public data | `tools/verify_no_private_provenance.py` — **written, correct, and in no workflow.** The highest-value one-line CI addition available. |

## The accounting question

"The ₹10,000 top-up bought how many PDFs, and which ones?"

    python3 tools/cost_ledger.py --report --since 2026-09-01

Two honest limits on today's answer:

1. **The per-page rates are list price, not invoice.** Every backfilled row says
   so in its `note`. Reconcile against the real invoices before quoting these
   numbers to anyone outside the project.
2. **75 of 86 billed works have no source PDF recorded.** They were OCRed before
   `ocr_sources.json` existed, and the URLs are not in any repository. Cost per
   PDF is therefore computed over the 11 works whose source is known. Filling
   the other 75 is real work, and until it is done the ledger says "unknown"
   rather than guessing.
