Panchanga Glossary

Every Sanskrit term, code abbreviation, and modern astronomy word used across the EXP.C annotation and the panchanga engine — in English, Sanskrit (Devanāgarī + IAST), and Kannada.

Two things before you rely on this:

1. I read “Canada language” as Kannada (ಕನ಼್್) — the code's own naming (pubba, makha, sapthami) matches Karnataka panchanga usage, so that's a near-certain read. Say so if you meant something else.

2. I couldn't place “FMRA” exactly. My two best guesses are rma (a code variable — see the table near the bottom) or “ephemeris” (a term from our last conversation — see the last section). Both are covered below. Tell me exactly where you saw it and I'll add the real one.

These Sanskrit and Kannada renderings are my best effort, not a pandit's or a linguist's. The common sastric terms (tithi, nakshatra, ayanamsha, ekadashi, and so on) are standard and I'm confident in them; a few code-only abbreviations have no real Sanskrit source at all, and I've marked those honestly rather than inventing one.
Sanskrit Kannada

Core conceptsthe vocabulary everything else is built from

day-count
Ahargaṇa
saअहर्गणahargaṇa
kaಅಹರ್ಗಣ
“Count of days” — days elapsed since a fixed starting point, used instead of a calendar date. The one number this whole calculation runs on.
lunar day
Tithi
saतिथिtithi
kaತಿಥಿ
One of 30 tithis in a lunar month — each a 12° step of the Moon getting ahead of the Sun. Ekadashi is tithi #11 and #26.
lunar mansion
Nakshatra
saनक्षत्रnakṣatra
kaನಕ್ಷತ್ರ
One of 27 equal slices of sky the Moon passes through, about one per day.
zodiac sign
Rashi
saराशिrāśi
kaರಾಶಿ
One of 12 equal 30° slices of the sky. In the code, also used loosely as a unit of angle (“in rashi units”).
Sun / Moon
Ravi & Chandra
saरवि / चन्द्रravi / candra
kaರವಿ / ಚಂದ್ರ
The two bodies this whole calculation tracks — the tithi is defined entirely by the angle between them.
fortnight
Paksha
saपक्षpakṣa
kaಪಕ್ಷ
Half a lunar month. Shukla/Śukla (शुक्ल, ಶುಕ್ಲ) = waxing/bright fortnight. Krishna/Kṛṣṇa (कृष्ण, ಕೃಷ್ಣ) = waning/dark fortnight — hence “s.ekadashi” vs “k.ekadashi” in the code.
tithi #11
Ekadashi
saएकादशीekādaśī
kaಏಕಾದಶಿ
“The eleventh” — occurs twice a month, once per paksha. The observance this whole project is ultimately about.
tithi #10 / #12
Dashami & Dwadashi
saदशमी / द्वादशीdaśamī / dvādaśī
kaದಶಮಿ / ದ್ವಾದಶಿ
The tithis just before and just after Ekadashi — whether either one overlaps sunrise is what the observance-day rules turn on.
new / full moon
Amavasya & Purnima
saअमावास्या / पूर्णिमाamāvāsyā / pūrṇimā
kaಅಮಾವಾಸ್ಯೆ / ಹುಣ್ಣಿಮೆ
Tithi #30 and #15. Kannada everyday speech mostly uses its own colloquial words here (amāvāsye, huṇṇime) rather than the Sanskrit form directly.
time units
Ghatika & Vighatika
saघटिका / विघटिकाghaṭikā / vighaṭikā
kaಘಳಿಗೆ / ಗಳಿಗೆ
Traditional time units: 60 ghatika = 1 day (≈24 min each); 60 vighatika = 1 ghatika (≈24 sec each). The code calls vighatika “galige.”
precession offset
Ayanamsha
saअयनांशayanāṃśa
kaಅಯನಾಂಶ
The gap between the tropical zodiac (tied to the seasons) and the sidereal zodiac (tied to the fixed stars) — it grows slowly over centuries.
tropical / sidereal
Sayana & Nirayana
saसायन / निरयणsāyana / nirayaṇa
kaಸಾಯನ / ನಿರಯಣ
Sāyana = “with ayana [added]” = tropical. Nirayaṇa = “without ayana” = sidereal. This is exactly what the code's ssr (sāyana-spashṭa-ravi) variable name is built from.

How the position gets correctedthe calculation-stage vocabulary

mean position
Madhya
saमध्यmadhya
kaಮಧ್ಯ
“Mean/average” — a body's position assuming perfectly uniform motion, before any correction is applied.
anomaly
Kendra
saकेन्द्रkendra
kaಕೇಂದ್ರ
The angle between a body and its apogee (the point where it moves slowest) — this angle is what decides how big the next correction needs to be.
correction
Manda-phala
saमन्दफलmandaphala
kaಮಂದಫಲ
“Slow[-motion] result” — the equation-of-center correction that accounts for a body's real, non-circular orbit.
true position
Sphuta
saस्फुटsphuṭa
kaಸ್ಫುಟ
“True/manifest” — the corrected, real position, after the manda-phala has been applied. (Also spelled “sputa” in the code.)
apogee
Uchcha
saउच्चucca
kaಉಚ್ಚ
The point in a body's orbit where it moves slowest. For the Moon, this point itself slowly drifts over time.
daily motion
Gati
saगतिgati
kaಗತಿ
How fast a body moves per day — used to convert a remaining angular distance into a remaining amount of time.
latitude correction
Chara-khanda
saचरखण्डcarakhaṇḍa
kaಚರಖಂಡ
“Variable segment” — corrects for how the ecliptic rises at different rates at different latitudes. Depends on where you are; the code never says what location it assumed.
sine-table value
Jya
saज्याjyā
kaಜ್ಯಾ
“Chord” — the traditional term for a value looked up from a sine table, the ancient equivalent of calling sin().
arcminute/second
Kala & Vikala
saकला / विकलाkalā / vikalā
kaಕಲಾ / ವಿಕಲಾ
Sub-units of angle: 60 vikala = 1 kala = 1 arcminute (1/60 of a degree).
remainder
Shesha
saशेषśeṣa
kaಶೇಷ
How much of the current tithi or nakshatra is left to go — the code's esh variable is this word, abbreviated.

Observance & traditionthe vocabulary the code does not implement yet

vow / fast
Vrata
saव्रतvrata
kaವ್ರತ
A vow or observance — in this context, the Ekadashi fast itself.
the hard case
Viddha
saविद्धviddha
kaವಿದ್ಧ
“Pierced/touched” — when a tithi is touched by its neighbor right at sunrise. This is the exact situation the observance-day rules exist to resolve, and it's why Ekadashi dates sometimes differ between traditions.
breaking the fast
Parana
saपारणाpāraṇā
kaಪಾರಣೆ
The act, and the time window, for ending an Ekadashi fast.
tradition
Sampradaya
saसम्प्रदायsampradāya
kaಸಂಪ್ರದಾಯ
A named lineage of practice — e.g. Smarta (स्मार्त, ಸ್ಮಾರ್ತ) or Vaishnava (वैष्णव, ವೈಷ್ಣವ) — each of which can apply its own viddha rule to the same underlying tithi timing.
combination
Yoga
saयोगyoga
kaಯೋಗ
A named coincidence of conditions, e.g. Guru Pushya Yoga = Thursday falling on Pushya nakshatra.
solar transit
Sankranti
saसङ्क्रान्तिsaṅkrānti
kaಸಂಕ್ರಾಂತಿ
The Sun's move from one rashi into the next.
solstice / equinox
Ayana & Vishuva
saअयन / विषुवayana / viṣuva
kaಅಯನ / ವಿಷುವ
Ayana = the Sun's northward/southward turning point (solstice). Vishuva = day and night of equal length (equinox).
eclipse
Grahana
saग्रहणgrahaṇa
kaಗ್ರಹಣ
A solar or lunar eclipse — not yet computed anywhere in this project.

Modern engineering termsfrom the parts of our conversation that weren't about the old code

TermPlain-language meaning
EphemerisA table (traditionally) or a piece of software (today) that tells you exactly where a planet or the Moon was, is, or will be, at any given moment. My other best guess for “FMRA.”
Swiss EphemerisThe specific modern software library this project now uses to get accurate Sun/Moon positions, replacing the old code's approximation tables.
Sidereal / TropicalSame distinction as Nirayana/Sayana above, just the English astronomy names for it.
Julian DayA single running day-count astronomers use, similar in spirit to Ahargana but starting from a different (more recent) point.
ElongationThe angular distance between two bodies — here, Moon minus Sun — the one number that determines the tithi.
BisectionA simple way to pin down the exact moment something happens (like a tithi boundary) by repeatedly narrowing a time window in half.
API / CLIWays of operating a program. An API is how one program asks another to do something; a CLI (“command-line interface”) is how a person types a command to run a program directly.
Lahiri (ayanamsha)One specific, government-adopted value for the ayanamsha — there are a few competing ones, and which is used changes some dates slightly.
