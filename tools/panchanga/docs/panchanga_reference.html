What this program computesइदं प्रोग्राम् किं गणयतिಈ ಪ್ರೋಗ್ರಾಂ ಏನನ್ನು ಲೆಕ್ಕಿಸುತ್ತದೆ

Given m (Ahargana — days elapsed from an epoch, hardcoded below instead of taken as input), the program computes the Sun's and Moon's longitude from a handful of terms of a traditional trigonometric table, finds their angular separation, and prints which of the 30 tithis is current — including both s.ekadashi and k.ekadashi — plus how much of it remains, and the same for the current nakshatra. It does not compute sunrise, and takes no location input at all.m (अहर्गणः, अर्थात् एकस्मात् आरम्भबिन्दोः गताः दिनाः, अत्र उपयोक्त्रा न दत्तः अपि तु सङ्केते एव स्थापितः) दत्ते सति, इदं प्रोग्राम् पारम्परिकज्याकोष्ठकस्य किञ्चित्पदैः रवेः चन्द्रस्य च रेखांशौ गणयति, तयोः कोणान्तरं निश्चित्य, वर्तमानां त्रिंशत्तिथिषु काम् (s.ekadashi, k.ekadashi इत्यादिसहितम्) इति, तस्याः शेषकालं च, तथैव वर्तमानं नक्षत्रं तस्य च शेषकालं मुद्रयति। सूर्योदयस्य गणना अत्र नास्ति, स्थानस्य अपि कोऽपि निवेशः नास्ति।m (ಅಹರ್ಗಣ — ಒಂದು ಆರಂಭಬಿಂದುವಿನಿಂದ ಕಳೆದ ದಿನಗಳ ಸಂಖ್ಯೆ, ಇಲ್ಲಿ ಬಳಕೆದಾರರಿಂದ ಪಡೆಯದೆ ಕೋಡ್‌ನಲ್ಲೇ ಸ್ಥಿರವಾಗಿ ಬರೆಯಲಾಗಿದೆ) ಕೊಟ್ಟಾಗ, ಈ ಪ್ರೋಗ್ರಾಂ ಸಾಂಪ್ರದಾಯಿಕ ಜ್ಯಾ-ಕೋಷ್ಟಕದ ಕೆಲವು ಪದಗಳಿಂದ ರವಿ ಮತ್ತು ಚಂದ್ರರ ರೇಖಾಂಶವನ್ನು ಲೆಕ್ಕಿಸಿ, ಅವುಗಳ ನಡುವಿನ ಕೋನಾಂತರವನ್ನು ಕಂಡುಹಿಡಿದು, 30 ತಿಥಿಗಳಲ್ಲಿ ಯಾವುದು ಈಗ ನಡೆಯುತ್ತಿದೆ ಎಂಬುದನ್ನು (s.ekadashi ಮತ್ತು k.ekadashi ಸೇರಿದಂತೆ) ಮತ್ತು ಅದು ಎಷ್ಟು ಬಾಕಿ ಇದೆ ಎಂಬುದನ್ನು, ಹಾಗೆಯೇ ಪ್ರಸ್ತುತ ನಕ್ಷತ್ರವನ್ನೂ ಮುದ್ರಿಸುತ್ತದೆ. ಇದು ಸೂರ್ಯೋದಯವನ್ನು ಲೆಕ್ಕಿಸುವುದಿಲ್ಲ, ಸ್ಥಳದ ಯಾವುದೇ ಇನ್‌ಪುಟ್ ಅನ್ನೂ ತೆಗೆದುಕೊಳ್ಳುವುದಿಲ್ಲ.

Swiss EphemerisThe specific modern software library (pyswisseph) this project now uses to get accurate Sun/Moon positions, replacing the old code's approximation tables.अस्मिन् प्रकल्पे अधुना प्रयुक्तः विशिष्टः आधुनिकः सॉफ्ट्वेयर्-पुस्तकालयः (pyswisseph), यः यथार्थं रवि-चन्द्रस्थानं ददाति।ಈ ಯೋಜನೆಯಲ್ಲಿ ಈಗ ಬಳಸುತ್ತಿರುವ ನಿರ್ದಿಷ್ಟ ಆಧುನಿಕ ಸಾಫ್ಟ್‌ವೇರ್ ಲೈಬ್ರರಿ (pyswisseph), ಇದು ಹಳೆಯ ಕೋಡ್‌ನ ಬದಲಿಗೆ ನಿಖರವಾದ ಸೂರ್ಯ/ಚಂದ್ರ ಸ್ಥಾನಗಳನ್ನು ನೀಡುತ್ತದೆ.
Sidereal / TropicalSame distinction as Nirayana/Sayana above, just the English astronomy names for it.उपरि उक्तयोः निरयण-सायनयोः एव भेदः, केवलं आङ्ग्लखगोलशास्त्रस्य नाम्ना।ಮೇಲೆ ಹೇಳಿದ ನಿರಯಣ/ಸಾಯನದ ಅದೇ ವ್ಯತ್ಯಾಸ, ಕೇವಲ ಇಂಗ್ಲಿಷ್ ಖಗೋಳಶಾಸ್ತ್ರದ ಹೆಸರಿನಲ್ಲಿ.
Julian DayA single running day-count astronomers use, similar in spirit to Ahargana but starting from a different (more recent) point.खगोलज्ञैः प्रयुक्ता एका सतता दिनगणना, अहर्गणस्य समानभावेन किन्तु अन्यस्मात् बिन्दोः आरब्धा।ಖಗೋಳಶಾಸ್ತ್ರಜ್ಞರು ಬಳಸುವ ಒಂದು ನಿರಂತರ ದಿನಗಳ ಎಣಿಕೆ, ಅಹರ್ಗಣದಂತೆಯೇ ಆದರೆ ಬೇರೆ ಬಿಂದುವಿನಿಂದ ಆರಂಭವಾಗುತ್ತದೆ.
ElongationThe angular distance between two bodies — here, Moon minus Sun — the one number that determines the tithi.द्वयोः ग्रहयोः मध्ये कोणदूरता — तिथिं निर्धारयति यत् एकं मानम्।ಎರಡು ಗ್ರಹಗಳ ನಡುವಿನ ಕೋನದ ಅಂತರ — ತಿಥಿಯನ್ನು ನಿರ್ಧರಿಸುವ ಒಂದೇ ಸಂಖ್ಯೆ.
BisectionA simple way to pin down the exact moment something happens (like a tithi boundary) by repeatedly narrowing a time window in half.कस्यचित् घटनायाः यथार्थक्षणं ज्ञातुं सरलः उपायः — कालखण्डं पुनः पुनः अर्धीकृत्य सङ्कोचयति।ಯಾವುದೋ ಘಟನೆ ನಿಖರವಾಗಿ ಯಾವಾಗ ಸಂಭವಿಸುತ್ತದೆ ಎಂದು ಕಂಡುಹಿಡಿಯುವ ಸರಳ ವಿಧಾನ — ಸಮಯದ ವ್ಯಾಪ್ತಿಯನ್ನು ಮತ್ತೆ ಮತ್ತೆ ಅರ್ಧಕ್ಕೆ ಇಳಿಸುತ್ತಾ ಹೋಗುವುದು.
API / CLIWays of operating a program. An API is how one program asks another to do something; a CLI ("command-line interface") is how a person types a command to run a program directly.प्रोग्राम् चालनस्य उपायौ। API इति एकः प्रोग्राम् अन्यं किमपि कर्तुं याचते इति रीतिः; CLI इति मनुष्यः स्वयं आदेशं टङ्कयित्वा प्रोग्राम् साक्षात् चालयति इति रीतिः।ಒಂದು ಪ್ರೋಗ್ರಾಂ ಅನ್ನು ಕಾರ್ಯಗತಗೊಳಿಸುವ ವಿಧಾನಗಳು. API ಎಂದರೆ ಒಂದು ಪ್ರೋಗ್ರಾಂ ಇನ್ನೊಂದನ್ನು ಏನಾದರೂ ಮಾಡಲು ಕೇಳುವ ವಿಧಾನ; CLI ಎಂದರೆ ವ್ಯಕ್ತಿ ಸ್ವತಃ ಆಜ್ಞೆ ಟೈಪ್ ಮಾಡಿ ಪ್ರೋಗ್ರಾಂ ಚಲಾಯಿಸುವ ವಿಧಾನ.
Lahiri (ayanamsha)One specific, government-adopted value for the ayanamsha — there are a few competing ones, and which is used changes some dates slightly.अयनांशस्य एकः विशिष्टः, शासनेन स्वीकृतः मान्यता — अन्ये स्पर्धमानाः अपि सन्ति।ಅಯನಾಂಶಕ್ಕಾಗಿ ಸರ್ಕಾರ ಅಂಗೀಕರಿಸಿದ ಒಂದು ನಿರ್ದಿಷ್ಟ ಮೌಲ್ಯ — ಸ್ಪರ್ಧಿಸುವ ಇನ್ನೂ ಕೆಲವು ಇವೆ.
