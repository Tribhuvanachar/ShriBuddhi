# Original sources

The four custom C/C++ programs this package's `legacy/exp_c_reference.py`
is ported from, copied here verbatim from the uploaded
`TC_new_final.zip` (`TC_new_final/TC_new_final/BIN/`) for reference. The
surrounding Turbo C 3.0 IDE distribution (compiler, linker, .BGI/.CHR
files, hundreds of editor swap files) is not included here — irrelevant
and, for the Borland-authored parts, not this project's to redistribute.

See `../SPEC.md` Sec 1 for what each file does and how they relate.
