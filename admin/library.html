ℹ️ Legend & Help
Curate the public Library without touching the corpus. Every edit here is a non-destructive override — reorder, pin, rename, move between folders, or hide. This tool starts from the committed library-overrides.json — the very file the app's Library reads — so what you see here is what readers see. Edits become a draft in this browser (the header shows when it differs from committed); click Export overrides to download the file and commit it to admin/config/ to publish, or ↺ Load committed to discard the draft. ➕ New folder adds a display-layer folder anywhere; move entries into it and it appears in the app. Folders always sort before granthas — same as in the app.
