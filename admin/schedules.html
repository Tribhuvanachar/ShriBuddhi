⌂ DGE Schedules what runs automatically, and when (India time)

Every automatic job is listed here. One workflow, Scheduler, wakes every hour and starts whichever job below is due, so changing a time here changes the real schedule from the next hour on — no code change, no pull request. Times are IST; the format is minute hour day-of-month month weekday (weekday 0 = Sunday). A job set for 02:00 starts at the first wake-up after 02:00, usually within a few minutes. Nothing here publishes to Jagat: that stays a manual run.
