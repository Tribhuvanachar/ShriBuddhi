Finalise — merge approved text into the library

Runs ocr-review-merge.yml on GitHub: it reads the saved decisions, builds the layer, validates, and opens a pull request for you to merge. Nothing reaches readers until that PR is merged; the nightly job then registers the folder in the library.

Decisions are saved beside the staged file as review/<name>.decisions.json on the same branch, one commit per save, and can be resumed by anyone with the passkey. Page images come from the ocr-images/<work> branch (rendered free by ocr-preview-pages.yml). The merge tool is tools/ocr_review_merge.py. Staging formats and the whole pipeline: docs/OCR_REVIEW.md.
