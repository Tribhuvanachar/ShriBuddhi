🔑 AI Provider Keys

Add a key for any AI provider you'd like Acharya to use. If you don't have one, contact sanatanavidyagurukulam@gmail.com. Keys are stored only on this device.

⚙️ Ask Acharya Settings

Checkboxes are fixed wording (can't be mistyped). Use "Additional instructions" for anything not covered.

🔊 Audio Source

Every grantha's own audio identifier/filename stays the same — this only changes the shared host prefix, on this device only. Leave blank to use the project default (https://archive.org/download/).

🔎 Search Index Source

Where the full-text search index (used by 🔎 global search) is fetched from, on this device only. Takes effect the next time this page loads. Leave blank to use the project default (a pinned jsDelivr build).

Used when you tap "⬇️ Image" or "🖼️ Share as Image" for any shloka.
